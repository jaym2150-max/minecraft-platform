# Roadmap

Our planned and in-progress work.

## Completed ✅

- [x] Core monorepo scaffolding
- [x] User authentication (register, login, JWT)
- [x] Project CRUD with categories and loaders
- [x] Version management with file uploads
- [x] Search powered by Meilisearch
- [x] File malware scanning (ClamAV)
- [x] Image processing pipeline
- [x] Notification system
- [x] Admin panel
- [x] Public documentation site
- [x] TypeScript SDK
- [x] Background workers (upload, virus, image, search, analytics, notification)

## In Progress 🚧

- [ ] OAuth 2.0 / GitHub sign-in
- [ ] Two-factor authentication (TOTP)
- [ ] Email verification flow
- [ ] Refresh tokens
- [ ] Modpack support (CurseForge packs)
- [ ] WebSocket real-time notifications
- [ ] GraphQL API alongside REST
- [ ] Discord bot integration
- [ ] Patreon/GitHub Sponsors integration for creator funding

## Planned 📋

### Q1 2026
- Plugin marketplace (separate from mods)
- Server hosting partnership program
- Donation/tip jar for authors
- In-app analytics dashboard v2
- Custom themes for project pages

### Q2 2026
- Mobile apps (iOS, Android) - read-only browsing
- API v2 with breaking changes for GraphQL migration
- Translation/i18n platform
- Premium tiers (priority uploads, custom domains)

### Future
- AI-powered mod recommendations
- Server hosting integration (one-click deploy)
- Cross-platform mod sync
- Real-time collaboration on projects
- Voice/video chat for teams
